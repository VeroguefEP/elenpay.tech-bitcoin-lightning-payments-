A REST API built for production Lightning payments

ElenPAY is a Lightning Payments Provider that lets your backend create automated Lightning invoices, keep them live and connected to your checkout, receive real-time payment confirmations via webhook, initiate payouts, and query settlement status, so your team retains full control of the payment experience. At the same time, ElenPAY manages node infrastructure, channel liquidity, and routing for you.

FAQ

Frequently Asked Questions

Common questions from developers and engineering leads evaluating ElenPAY's API. You can also explore our Lightning Knowledge Hub or speak with our team directly.

What is ElenPAY's Lightning API?+
ElenPAY's Lightning API is a production-ready REST API that enables businesses to programmatically accept and send Bitcoin Lightning payments. It exposes endpoints for invoice creation, payment status webhooks, payouts, and settlement queries, giving developers full control over the payment flow while ElenPAY manages the Lightning node infrastructure, liquidity, and routing.
How long does it take to integrate ElenPAY's Lightning API?+
ElenPAY's REST API is designed to be integrated in hours, not weeks. The sandbox environment lets developers test invoice creation, payment flows, and webhook handling against a live Lightning testnet before going live. ElenPAY provides expert integration guidance and 24/7 technical support throughout the process.
Does ElenPAY's API support both pay-ins and payouts?+
Yes. The API supports pay-ins (receiving Lightning payments from customers), payouts (sending Lightning payments to users, affiliates, or partners), and mass payouts — sending to multiple recipients simultaneously. This makes it suitable for iGaming platforms, creator platforms, and marketplaces with distributed payout requirements.
What does the webhook payload look like?+
When a Lightning invoice is paid, ElenPAY fires an HTTPS POST request to the webhook URL specified in the invoice creation call. The payload includes the payment identifier, amount in satoshis, settlement timestamp, and status field. Your backend acknowledges the webhook with a 200 response, and funds are credited to your back office in real time.
Is there a sandbox environment for testing?+
Yes. ElenPAY provides a full sandbox environment that mirrors production behaviour — invoice creation, payment simulation, and webhook delivery — without settling real funds. Developers can test end-to-end payment flows against Lightning testnet before requesting production API credentials.
What settlement speed and fees does ElenPAY's API deliver?+
Lightning payments processed through ElenPAY's API settle in under one second. Network fees are below $0.01 per transaction. There are no chargebacks. Funds are credited to your back office the moment the customer pays — no clearing windows, no float.
Can the API handle high-frequency payment environments?+
Yes. ElenPAY's Lightning infrastructure supports over 100,000 transactions per second, making the API suitable for iGaming platforms, high-frequency trading environments, and any application requiring concurrent payment processing at scale.
